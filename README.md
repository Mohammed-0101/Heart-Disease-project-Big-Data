<h1>Heart Disease Big Data</h1>

<p>this project aims to make website , it can control on database was created in MongoDB.</p>

<h2>Features</h2>
<ul>
  <li>MongoDB</li>
  <li>Python</li>
  <li>DataPrep</li>
  <li>Random Forest</li>
  <li>Pywebio</li>  
</ul>

<h2>Steps</h2>
<p>1- Create NoSQL Database on <b>MongoDB</b> there are some picture on folder "Pictures for data in MongoDB" </p>
<p>2- Connect between MongoDB and python by using <b>pymongo</b> package </p>
<p>3- Using <b>DataPrep</b> library to make visualization for cleaned data</p>
<p>4- We use <b>Random Forest</b> Model to predicte the possibility of Heart Disease occurring</p>
<p>The Model achieved an accuracy of 86%</p>
<p>5- Create website by using <b>pywebio</b> package in python </p>
<p>6- Through this website we can Delete , Add , Remove , Update the data</p>
<p>And we can show the visualizatoions of the data</p>
